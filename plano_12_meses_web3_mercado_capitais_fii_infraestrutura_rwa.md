# 4. Certificações: ordem recomendada

## 4.1 CFG — primeira prioridade

A **CFG — Certificação ANBIMA de Fundamentos em Gestão** deve ser sua primeira certificação de mercado.

Ela funciona como uma ponte entre sua formação tecnológica e o vocabulário de gestão profissional de recursos.

### Assuntos prioritários

- [ ] Economia.
- [ ] Matemática financeira.
- [ ] Estatística.
- [ ] Contabilidade.
- [ ] Finanças corporativas.
- [ ] Renda fixa.
- [ ] Renda variável.
- [ ] Derivativos.
- [ ] Teoria de carteiras.
- [ ] Risco.
- [ ] Ética.
- [ ] Regulação.
- [ ] Gestão de recursos.

### Objetivo

Não apenas passar na prova.

O objetivo é conseguir entender uma reunião de uma asset e conversar tecnicamente com gestores e analistas.

---

## 4.2 CGE — segunda prioridade para fundos estruturados

Depois da CFG, avaliar a **CGE — Certificação de Gestores ANBIMA para Fundos Estruturados**.

É especialmente interessante para uma especialização em:

- FII;
- FIP;
- FIDC;
- FIAGRO;
- estruturas alternativas.

### Particularmente relevante para

```text
FII
 │
 ├── imóveis
 ├── CRI
 ├── desenvolvimento
 └── renda imobiliária

FIP
 │
 ├── private equity
 ├── participação societária
 └── infraestrutura

FIP-IE
 │
 └── empresas/projetos de infraestrutura
```

---

## 4.3 CGA — avaliar para a trilha FI-Infra/renda fixa

A **CGA** passa a ser especialmente interessante caso você queira aprofundar:

- renda fixa;
- crédito privado;
- debêntures;
- fundos de renda fixa;
- FI-Infra;
- gestão de carteira.

Não há necessidade de tentar fazer CFG + CGE + CGA simultaneamente.

### Ordem sugerida

```text
CFG
 │
 ├──────────────► CGE
 │                  │
 │                  ├── FII
 │                  ├── FIP
 │                  └── FIP-IE
 │
 └──────────────► CGA
                    │
                    ├── Crédito privado
                    ├── Debêntures
                    ├── Renda fixa
```

# 18. Testes financeiros

Não teste apenas o código.

Teste a economia do sistema.

Exemplos:

```text
NAV nunca pode ficar inconsistente
```

```text
totalAssets >= liabilities
```

```text
tokenSupply deve reconciliar com registro
```

```text
DvP não pode entregar somente um dos lados
```

```text
investidor bloqueado não pode receber token
```

```text
distribution <= distributableCash
```

```text
redemption não pode ultrapassar liquidez disponível
```

Use Foundry invariants e fuzzing.
