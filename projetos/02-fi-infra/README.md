# Projeto 2 — painel de FI-Infra

**Objetivo:** construir API de carteira fictícia de debêntures de infraestrutura, duration, stress, rating interno ilustrativo e covenants/DSCR.

`src/` contém serviço Node.js e modelos de cenário; `contracts/` opcional para âncora de hash de relatórios; `docs/` registra fontes, premissas e limites. Dataset sintético sem cotação/identidade real.

Entregas: duration e spread duration por posição, cenário paralelo e key-rate, caixa do projeto, DSCR contratual, alerta de covenant e histórico de revisão. Nunca inferir elegibilidade fiscal só do rótulo do ativo.
