# Projeto 3 — acompanhamento de FIP-IE

Modelo de capital calls, participação em SPE, orçamento CAPEX/OPEX, cronograma físico-financeiro, licenças, waterfall, valor residual, TIR e MOIC. A classe de teste não é fundo real e não implementa oferta.

Entregas em `src/`: modelo determinístico e cenários; `contracts/`: registro de eventos de aporte em ambiente local; `docs/`: matriz de risco regulatório, lista de diligência, covenant e trilha de evidências. O cálculo de elegibilidade tributária será regra versionada referenciada, nunca promessa automática.
