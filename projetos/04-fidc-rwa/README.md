# Projeto 4 — FIDC de recebíveis sintéticos

Pipeline para lote sintético: validar schema, deduplicar, checar elegibilidade, registrar hashes/documentos simulados, calcular atraso, perdas, subordinação e waterfall.

Entregas em `src/`: Node.js ingest/API; `contracts/`: prova de lote e eventos não financeiros; `docs/`: dicionário de dados, controles de lastro, servicing, LGPD, reconciliação e stress. Hash não verifica autenticidade nem validade de crédito. Não usar documentos pessoais reais.
