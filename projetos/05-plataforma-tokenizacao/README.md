# Projeto 5 — plataforma de tokenização RWA

Capstone modular para simular onboarding, elegibilidade, oferta fechada fictícia, registro de titularidade de teste, restrições de transferência, eventos, distribuição e reconciliação. Separar domínio, API, contratos, identidade, consentimentos, custódia e livro oficial.

Entregas: threat model; arquitetura e trust boundaries; contrato com papéis/pausa/limites; API Node.js idempotente; processamento de eventos; reconciliação diária; plano de recuperação de chave e incidentes; matriz norma-controle-evidência. Não conectar a ativos ou investidores reais.
