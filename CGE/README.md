# CGE — Certificação de Gestores ANBIMA para Fundos Estruturados

A CGE habilita profissionais a atuar com gestão de recursos de terceiros em FII, FIDC e fundos de índice. Foco em fundos estruturados: underwriting, estrutura de capital, governança, valuation e operação. Pré-requisito: CFG, CFA ou CAIA.

## Sobre o exame

| Característica | CGE |
|---|---|
| Habilitação | Gestor de fundos estruturados (FII, FIDC, ETF) |
| Pré-requisito | CFG, CFA ou CAIA |
| Questões | 60 |
| Duração | 3 horas |
| Aprovação | 70% (42 acertos) |

## Distribuição dos temas

| Tema | Proporção |
|---|---|
| 1. Investimentos imobiliários (FII) | 9–13% |
| 2. Private equity (FIP) | 9–13% |
| 3. Securitização de recebíveis (FIDC) | 9–13% |
| 4. Fundos de índice (ETF) | 9–13% |
| 5. Investimentos no exterior | 9–13% |
| 6. Avaliação de desempenho | 9–13% |
| 7. Gestão de risco | 11–15% |
| 8. Legislação, regulação e tributação | 18–22% |

> **Dica estratégica:** O tema 8 (legislação) pode representar até 22% da prova — é o de maior peso. Os temas 1 a 6 juntos somam até 78%, mas são distribuídos de forma uniforme.

## Como estudar

Se este for seu primeiro contato com fundos, leia antes [fundos, papéis e estruturas](../INTRODUÇÃO/04-fundos-e-estruturas.md). Para cada veículo, acompanhe o dinheiro da origem até o investidor: quem aporta, qual ativo é adquirido, de onde vem o caixa, quais despesas e classes têm prioridade e que evento pode interromper os pagamentos. Compare cenário base com adverso e explique quem absorve a perda primeiro.

As explicações são didáticas; limites, deveres de prestadores, elegibilidade e tributação devem ser conferidos nos textos consolidados, regulamentos e documentos da classe/oferta.

## Base normativa

Resolução CVM 175: Parte Geral + Anexo II (FIDC), Anexo III (FII), Anexo IV (FIP), Anexo V (ETF); Anexo I inclui FI-Infra no segmento de fundos financeiros incentivados. Combine com Lei 8.668/1993 (FII), Lei 11.478/2007 (FIP-IE), Lei 12.431/2011 (infraestrutura), Resolução CVM 160 (ofertas) e normas tributárias vigentes.
