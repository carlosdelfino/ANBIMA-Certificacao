## Baixar as cópias

O download automático não foi concluído neste ambiente, pois o DNS de saída falhou. Execute, quando houver acesso de rede:

```bash
python3 scripts/download_normas.py
```

O script usa links diretos oficiais e baixa a Resolução 175 e as Resoluções 19, 20 e 21 em `normas/`. Até a execução bem-sucedida, os documentos são acessados pelos links oficiais acima.
